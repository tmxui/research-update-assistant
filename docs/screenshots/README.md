# Screenshot-Checkliste

Empfohlene Aufnahmen für die GitHub-Projektseite:

1. **PDF-Prüfung** – synthetisches PDF, ausgewählte Kennzahl und sichtbare Quelle
2. **Finanzhistorie** – FY2023 bis FY2025 mit Periodenauswahl
3. **Ergebnis-Update** – Headline-KPIs, Veränderungen und Research-Prüfpunkte
4. **Erwartungen und Guidance** – ausschließlich synthetische Snapshot-Werte
5. **Export** – Periodenauswahl sowie Excel- und CSV-Download

Vor jeder Aufnahme prüfen:

- nur synthetische Daten oder ein öffentlicher Geschäftsbericht
- keine lokalen Dateipfade, Browserprofile oder Benutzernamen sichtbar
- keine internen Research-Texte, Modelle, Tokens oder Secrets
- konsistente Fenstergröße und aktueller V1-Stand
- offene Detailbereiche nur dann einblenden, wenn sie den gezeigten Workflow erklären

Bilddateien können später in diesem Ordner abgelegt und aus der Haupt-README
verlinkt werden. Aktuell werden bewusst keine automatisch erzeugten Screenshots
versioniert.
